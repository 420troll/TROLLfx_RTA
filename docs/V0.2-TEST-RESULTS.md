# V0.2 automated verification results

Command: `scripts/run-tests.sh`

The deterministic DSP suite passed all 24 checks:

- 50 Hz, 100 Hz, 1 kHz, 5 kHz, and 10 kHz band location
- Hann-window RMS normalization and 1 kHz band confinement
- Silence floor, deterministic white noise, pink noise, off-bin leakage, multi-tone separation, and logarithmic sweep coverage
- Parsing both serial 7033298 calibration files, retaining 2.7673 dB Sens Factor, distinct 0°/90° response curves, and orientation-specific spectral correction
- Exact calibration knots, log-frequency interpolation, SPL sensitivity conversion, and A-weight response

The same test command benchmarks the old V0.1.2 8,192-point analyzer against the V0.2 32,768-point PFFFT analyzer. One representative x86-64 host run measured 0.543 ms/frame for V0.1.2 and 0.838 ms/frame for V0.2. V0.2 analyzes four times as many samples per frame; the timing is host-only and varies with CPU frequency and system load.

Command: `scripts/build-armv7.sh`

Cross-compilation succeeded. `dist/trollfx-rta-v02-armv7` is an ELF 32-bit ARM EABI5 PIE, ARMv7-A, hard-float, with NEON enabled. The matching PFFFT third-party notice is `dist/THIRD_PARTY_NOTICES.txt`.

No Force or UMIK hardware was available for this verification. ALSA continuity, Force CPU load, USB input gain, calibrated SPL accuracy, and the 8096 browser UI remain for manual Force testing. The build and test results do not claim those hardware checks passed.
