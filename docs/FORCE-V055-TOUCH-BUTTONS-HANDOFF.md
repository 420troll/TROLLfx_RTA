# V0.5.5 hardware UI repair handoff

Base: `feature/v054-continuous-sweep-graph`. Branch: `feature/v055-touch-buttons`.

## Changes already committed
- SWEEP page uses the MPC Plugin Builder SDK's documented native `Button` control for **START SWEEP** (param 115) and **CANCEL / FADE** (param 116), in place of the prior slider. Existing momentary `onParameterChange` logic resets both to 0 and handles start/cancel without changing parameter indices.
- Eight **saved measurement selectors** are radio-group `Button` components on new `SAVED SWEEPS` page; all bind to existing choice param 123 with `buttonId` 0..7 and `numButtonsInGroup` 8.
- On/off artwork is generated by `scripts/generate-force-rta-skin.py` with Pillow. Existing knob/Q-Link choice remains usable. This is **selection of Latest / Previous 2–8**, not creation of eight named/persistent save slots. All completed sweeps continue to save automatically in Service/sessions.
